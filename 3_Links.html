When the user clicks the link, the default email application can open with the specified email address. Syntax: Send Email Example: Email Me A subject can also be included: Send Email // NOTES Telephone links use the `tel:` scheme. They allow users to click a phone number and initiate a call on supported devices. Syntax: Call Us Example: +91 12345 67890 The `tel:` link is especially useful on mobile devices. // NOTES The `target` attribute specifies where the linked page should open. Common values: 1. `_self` * Opens the link in the current tab. * This is the default. 2. `_blank` * Opens the link in a new tab/window. 3. `_parent` * Opens the link in the parent browsing context. 4. `_top` * Opens the link in the full browser window.
